## Parser defect found and corrected

The first real execution parsed only 590 Samir rows because numeric strings such as `3,878.00` were rejected. The parser was corrected to accept comma grouping only when every group after the first contains exactly three digits. Malformed grouping is rejected rather than guessed.

Regression tests cover valid grouped decimals, malformed groupings and precision preservation. The successful full archive run then parsed all 52,369 Samir rows and all 52,387 SocrateAI rows with zero rejected rows.
