## Implemented research controls
- Record-date unsettled sale overlap rejected, including settlement day.
- Explicit purchase-lot allocations, partial disposal and fee-inclusive realized P&L.
- Action-free ledger adapter matches opening quantities/costs, purchases, sales and ending quantities.
- Snapshot bonus/split/rights/dividend adjustments require unchanged lots.
- Dividend replay handles intervening settled sales; scheduled receipt is not cash.
- Pending assets segregated; confirmation deltas are not automatically applied.
- Dashboard blocks new entry risk gate on missing or unresolved corporate asset evidence, preserves existing exit review for valid inputs.

## Open blockers
- Persistent receipt idempotency across requests is absent. Duplicate IDs within a request are rejected, not cross-request duplicate credits.
- Full chronological bonus/split/rights lot replay and independent custody entitlement verification absent.
- Dividend replay and ledger lot adapter lack dedicated integration coverage.
- Ledger aggregate average cost is not reconciled to explicit lot cost after sales.
- Risk denominator excludes pending assets; drawdown can overstate loss; complete fair value is not independently verified.
- Historical marks, calendars, fee/tax rules and per-event availability require independent evidence. Same-day first-session risk sizing can use same-day close; do not claim point-in-time backtest readiness.
- Pending asset coverage is caller attested; empty arrays do not establish completeness. Invalid overlay input can reject entire dashboard request.
- No production execution, UI deployment or verified profitability.
