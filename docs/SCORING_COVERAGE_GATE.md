# V3 scoring and coverage gate

## Purpose
This module provides the common composite-score contract for the NEPSE V3
scanner. It is deliberately separate from technical feature extraction:
upstream engines must supply evidence-backed 0–100 component values.

## Component weights
| Component | Weight |
|---|---:|
| Wyckoff | 25% |
| Minervini trend | 25% |
| Relative strength | 15% |
| Broker footprint | 10% |
| Volume/VSA | 10% |
| Liquidity/tradability | 5% |
| Sector strength | 5% |
| SMC confirmation | 5% |

## Missing-data policy
- A missing component remains null and contributes no weight.
- The composite is normalized over available component weights only.
- Coverage is reported separately; a high partial score is never presented as
  a complete score.
- Coverage below 80% is insufficient and results in NO_TRADE.
- Coverage from 80% to below 100% is provisional and cannot produce BUY.
- Full coverage is required for BUY.

## BUY gate
BUY additionally requires HIGH Stage-1 data quality, confirmed structure,
verified tradability/liquidity, a tradeable market, reward/risk of at least
2R, and no hard-block flags. Any hard block forces NO_TRADE. Other unmet
prerequisites result in WAIT.

## Interpretation
The output is a rules-based research classification, not a probability or
guarantee. No probability is generated by this module. Broker observations
remain execution-channel data and are not proof of beneficial ownership or
manipulation. The module does not alter source records, historical identity,
corporate-action treatment, or Stage-1 eligibility.
