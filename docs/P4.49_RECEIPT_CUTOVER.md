## Required operator procedure
1. Stop all legacy writers and verify no remaining processes can write. The source_frozen flag is an attestation, not a lock.
2. Take consistent SQLite backups using the backup API (not a raw copy of an active WAL database). Retain originals and hashes.
3. Use a fresh destination receipt projection, migrate from the frozen source, and retain imported/skipped counts.
4. Reconcile every portfolio against historical receipt events. Compare source and destination portfolio/action keys and payload hashes. Require zero unexplained differences.
5. Repeat migration; require zero imports and unchanged totals.
6. Do not add projected totals to external balances already reflecting receipts. They are cumulative credits, not spendable cash or current holdings.
7. If any check fails, quarantine destination and investigate; retain source. Do not silently repair or enable both writers.
