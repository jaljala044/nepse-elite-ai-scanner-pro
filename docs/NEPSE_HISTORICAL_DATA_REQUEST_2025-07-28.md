## Evidence acceptance checklist

Do not treat a response as primary evidence until the received file or written confirmation:

- identifies NEPSE as the issuing authority or is independently authenticated with NEPSE;
- identifies the session date as 2025-07-28 and the five exact symbols;
- contains the fields needed to resolve the disputed tuples, or explicitly documents which fields are unavailable;
- preserves the original file, receipt email/letter, retrieval timestamp, and SHA-256 hash;
- documents the closing-price methodology and any corrections/revisions.

A broker TMS export can be retained as a separate corroborating source, but it is not an NEPSE-issued EOD board unless NEPSE certifies it.
