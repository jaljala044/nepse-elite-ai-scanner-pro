## Evidence and method

- Re-used the exact pinned source commits and file objects from P4.19. The three-date comparison validated all source payload hashes and parsed rows before classifying one-sided records.
- Compared each source-only symbol with the 2026-11-25 security snapshot, the 2026-11-26 equity crosswalk and target-universe candidate registry.

- The classification is explicitly a **current-snapshot scope hint**. It is not an effective-dated security master for the 19/20/24 November trade dates and does not prove historical identity.
- Unknown or unclassified symbols remain explicit review states. No source completeness, exchange session completeness, source independence, rights, coverage admission or canonical promotion is inferred.

## Engineering safeguards

- The audit rejects incomplete source comparisons, shared-field conflicts, Samir-only contracts and trade-date mismatches before classifying.
- Snapshot dates and crosswalk/snapshot identities are validated.
- Candidate/snapshot security-ID conflicts fail closed.
- Bond classification uses token boundaries to avoid false positives such as “Bonded”.
- Every row records the scope-evidence temporality and sets `historical_security_identity_verified: false`.
- Added regression tests for bond-name matching, substring false positives, snapshot-date drift, candidate-ID mismatch and crosswalk/snapshot mismatch.
