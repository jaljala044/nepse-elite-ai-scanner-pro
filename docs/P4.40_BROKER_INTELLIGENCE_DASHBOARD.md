# P4.40 — Broker Intelligence Dashboard

## Purpose
Provide one point-in-time, read-only dashboard contract composing the verified daily broker ledger and rolling broker profiles (P4.36–P4.37), broker sector-rotation artifacts (P4.38), and early accumulation/distribution research candidates (P4.39).

## API
`POST /v1/research/broker-dashboard`

The request supplies:
- `as_of_date` and timezone-aware `as_of_timestamp`.
- `rolling_profiles`: the upstream P4.37 result, with daily, weekly, monthly and yearly windows requested upstream.
- `source_manifest`: upstream status, source IDs, coverage and availability timestamp.
- `sector_rotation_by_window`: optional P4.38 artifacts keyed by daily/weekly/monthly/yearly.
- `candidates`: optional P4.39 candidate outputs.

This is a composition endpoint, not a raw-source ingestion connector. It does not independently verify files, exchange sessions, broker identity, source controls or upstream attestations. Its response explicitly marks that provenance boundary.

## Dashboard sections
- Broker/security profile matrix: buy/sell/net/gross amounts and quantities, positive/negative/zero sessions, persistence, participation and daily series where upstream profiles support them.
- Four required windows: daily (1), weekly (5), monthly (21) and yearly (252) verified sessions.
- Sector rotation: prior/current windows, coverage, excluded rows and broker-sector participation changes for each supplied window.
- Early accumulation/distribution candidates: classification and confirmation-only action from P4.39; no probability is surfaced.
- Provenance and coverage: source IDs, coverage, as-of timestamps, excluded rows and explicit unavailable reasons.

## Safety and missing-data policy
- Missing windows and artifacts are UNKNOWN/unavailable, never zero.
- No profile values are surfaced when the supplied source manifest is unverified, late or below 95% coverage.
- Profile values are retained only when upstream status is descriptive_only and profile coverage meets the threshold.
- Upstream complete-session zero-activity values may be displayed as supplied; this layer does not synthesize missing broker/security/session rows.
- Late candidate or sector artifacts are withheld by the point-in-time cutoff.
- Broker flow and sector mix are descriptive; they do not prove beneficial ownership, intent, manipulation, accumulation, distribution or a trade signal.
- No BUY/SELL, entry, stop, target, probability or backtest result is generated.

## Verification
Unit tests cover all four horizons, missing-window UNKNOWN handling, manifest withholding, timestamp/date mismatches, late candidates and sector artifact as-of validation.
