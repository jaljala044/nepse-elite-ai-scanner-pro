## Open acceptance gates
1. Opening holdings require reconciled opening lots; current adapter rejects them.
2. Unified average-cost and explicit lot allocation differ legitimately; statutory tax method and historical rates require independent evidence.
3. Caller-attested records are not verified custody records. No official reconciliation or production certification.
4. Global evidence cutoff permits retrospective evidence; this is not a point-in-time trading decision replay.
5. Settlement-day availability differs between engines; exact intraday settlement confirmation is absent.
6. Chronological calendar may end before assessment date; nontrade corporate events may occur outside supplied sessions. Align explicit valuation and event cutoffs before certification.
7. Corporate action combinations, partial subscriptions, pending credits, multiple lots, duplicate/reordered events and mismatch cases need expanded cross-engine tests.
8. Persistent receipt credits are not yet an atomic transaction with actual portfolio holdings and cash.
9. Full accounting reconciliation flag remains false by design.
10. Review API error normalization, authorization and persistence before exposing reconciliation to users.
