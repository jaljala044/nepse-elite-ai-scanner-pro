# Daily market candidate handoff

The workflow `.github/workflows/daily-market-candidate-handoff.yml` is deliberately manual (`workflow_dispatch`) until a reviewed input-bundle producer and secure artifact retention location are provisioned.

Required bundle: `secure-input-bundles/YYYY-MM-DD.json`, generated by the approved ingestion/reconciliation process. The bundle must include the exact session calendar, verified equity universe, daily rows, benchmark rows, index rows, expected indices, stock rows, effective-dated sector membership, and timezone-aware decision time.

Run from Actions > Daily market candidate handoff with an exact NEPSE session date and timezone-aware decision time. The workflow produces candidate files and a review-required manifest only. It does not sign approvals, publish the trusted registry, or enable recommendations.

Do not change this workflow to a scheduled trigger until:
1. The bundle producer has a successful end-to-end run against independently reconciled records.
2. The input bundle is stored as a protected workflow artifact or secure mounted source (not a repository secret or public artifact).
3. The candidate output has a controlled retention destination.
4. The reviewer key is configured outside the repository and independent approval is operational.

A missing bundle is a hard failure, not an empty successful scan.
