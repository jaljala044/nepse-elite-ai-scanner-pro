## Observed source schema

Exact header:

\`\`\`csv
date,sn,contract_no,stock_symbol,buyer,seller,quantity,rate,amount
\`\`\`

The scraper code at the pinned commit:
- requests \`https://merolagani.com/Floorsheet.aspx\`;
- collects rows from the displayed table and paginates via the page's \`changePageIndex\` control;
- writes the value of Python \`date.today()\` to the CSV \`date\` field;
- records the page's serial number, contract number, symbol, buyer, seller, quantity, rate and amount;
- skips HTML table rows with fewer than eight cells.

Therefore the CSV \`date\` field is a **scrape/capture date generated by the script**, not an independently parsed exchange trade-date field. For this specific file, the MeroLagani page is displayed as of 2026-11-24 and the contract numbers all have the 20261124 prefix; this supports that date for this sample, but the source mapping remains provisional until the page-level totals and complete row set reconcile.

The repository README labels its data source as ShareSansar / Merolagani and its license badge as **Educational**. The pinned repository tree contains no \`LICENSE\` or \`COPYING\` file. This audit did not establish permission to redistribute the floorsheet data or use it in a commercial application. Do not promote or redistribute the capture until terms are clarified.

## Interpretation and use decision

1. The sample is internally coherent at the row level: 52,369 unique contracts, no quantity-rate-amount formula exceptions, and the first eight records match the MeroLagani page snippet.
2. The daily quantity and turnover do not reconcile to MeroLagani's page summary. Do not classify this file as a complete day. The 16 \`sn\` gaps are additional review candidates.
3. Do not silently add the MeroLagani page totals to the CSV, delete rows, or choose one value as correct. Preserve both source observations and the variance.
4. The 347 observed symbols exceed the project working scope of 281 equities + 47 mutual funds (328 symbols). Do not guess which 19 are out of scope; reconcile by security ID, instrument type and lifecycle status.
5. The source's \`date\` field is generated by \`date.today()\`; retain it as capture-date evidence and keep exchange trade date separately qualified.
6. No broker identity is verified by code alone. The 91 observed broker codes are source codes; resolve them only through effective-dated, evidence-backed broker links.
7. The repository's “Educational” license label and lack of an explicit license file leave data-use rights unresolved.

**Acceptance:** Samir sample acquisition/hash/header and row-level syntax/math checks complete; Samir's daily control reconciliation fails; SocrateAI's same-date file includes all Samir rows plus the 18 records that close Mero's controls; no shared-row conflicts. The SocrateAI source origin and rights remain unresolved, and the official 281 + 47 universe remains unverified. **Review only. No canonical storage or model-training promotion.**

### Revised conclusion

The earlier anomaly is now isolated: the Samir CSV is a 52,369-contract subset of a same-day 52,387-contract SocrateAI copy. Its 16 serial-number gaps include the 18-contract omission pattern only indirectly; the serial gaps must not be equated one-for-one with missing contracts. The 18 contracts are identified by transaction IDs in the comparison artifact, and their aggregate exactly closes the published daily control difference.

The SocrateAI copy is therefore the **better completeness candidate for 2026-11-24**, because it contains every Samir contract plus the 18 control-reconciling records. It is not yet accepted as canonical: provenance independence, exact original NEPSE source chain, rights and target-universe membership remain unresolved. Keep both copies, hashes, and the 18-record exception set in the source review ledger. Do not rewrite Samir's source file or promote either data source to training.
